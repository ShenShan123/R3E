# 作品简介

R³E 面向芯片前端设计中“RTL 能通过编译但功能仍错误、人工波形定位与回归验证成本高”的痛点。Competition M2 通过运行时 oracle evidence、Failure Descriptor、R³E Blue Candidate Portfolio、AST/Scope Gate 与 Icarus/Yosys 正确性门，形成“证据—路由—多候选—EDA选择”的可审计 RTL 纠错链。模型只提出 replacement RTL，runner 和真实 EDA 决定候选是否可接受；Evolution、Memory 与 benchmark 指标只有具备独立冻结证据时才展示。作品可用于 RTL 调试、验证辅助、EDA 智能化及数字芯片教学科研场景。
