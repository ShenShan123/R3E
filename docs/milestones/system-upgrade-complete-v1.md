# System Upgrade Complete V1

This milestone freezes the engineering infrastructure described by Phases
0–4 of `docs/design/Whole-Policy-Evolution.md`.

The authoritative machine-readable record is
`configs/evolution/system_upgrade_complete_v1.json`. Its hash binds the frozen
B0 policy, four-dimensional policy search space, six-operator lineage space,
round interface, stable software interfaces, validation commands, and explicit
experiment exclusions.

The milestone includes:

- fail-closed Oracle evidence and counterexample admission;
- Policy Registry V2 with one active policy, atomic promotion, exact rollback,
  retire, audit-fail, migration, and hash-chain ledgers;
- PolicyState-only formal repair with frozen prompt assets and bounded
  call/token/wall-time execution;
- active-policy-conditioned red generation, residual/covered archives,
  MAP-Elites selection, learnability teachers, and cross-round accumulation;
- all six lineage operators under a uniform deterministic materializer
  dispatch and runner-owned postcondition checks;
- adapter output conformance binding model, budget, verifier, toolchain,
  command, result, and output schema;
- resumable rounds, paired replay, renewed challenge, events, and offline
  round reconstruction;
- deterministic fake-adapter multi-round validation and public release checks.

This milestone does not freeze a model, experiment seed, promotion threshold,
non-target dataset, child count, or experiment budget. It does not claim a
real-model `B0→B1→B2` result. Those remain Phase 5/6 experiment inputs.
